# 《拆弹行动》产品路线

## 当前版本

Milestone A + B 已建立急性冲突处理基础。Milestone B.1 负责补齐缓和判断、明确退出、哭泣时的距离选择、可选身体联结，以及统一的“可以这样说”语义。

## Milestone D（未来需求，尚未实现）

未来顶层产品架构：

- 平时：积累 → 感恩、主动联结、保持好奇、制造高光时刻
- 冲突时：止损 → 停、稳、听、降低升级
- 冲突后：修复 → 理解、道歉、行为改变、后续检查

非冲突模式可以使用“给关系充点电”的概念，提供短小、可立即执行的关系行动卡，例如：

- 说一个具体的谢谢
- 主动接住 TA 的一次分享
- 制造一个小小的共同高光
- 问一个平时不会问的问题
- 一起做一点和平常不一样的事情

这些内容应当是行动卡，不做文章、测验、连续签到、分数或关系游戏化。
